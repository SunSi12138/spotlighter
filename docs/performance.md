## 已有测量与验证

本机：Ryzen 9 7950X、3840×2160 输出。此前硬件着色路径实际使用 RTX 3080；当前缓存上传设备枚举为 **Microsoft Basic Render Driver（WARP）**，并不依赖 RTX。

以下为界面和冷暖调整前的单图层 CPU 路径历史记录，**不代表最新版本的重新测量**。项目整理和灯具缩放变更没有追加性能测试：

| 逻辑照明尺寸 | 移动提交平均 / p95 | 进程 CPU（一个逻辑核心） | 工作集 |
| --- | --- | --- | --- |
| 1920×1080 | 0.041 / 0.064 ms | 0.31% | 41.62 MiB |
| 3840×2160 | 0.059 / 0.159 ms | 0.41% | 60.12 MiB |

两组输出都由真实 4K 桌面合成；1080p 是逻辑缓存场景，不是切换显示器到原生 1080p。4K 运行出现长停顿，15 秒目标实际持续 23.081 秒，因此不把该次提交 FPS 当作稳态帧率承诺。渲染调用墙钟不含 DWM 完整合成、扫描输出和物理输入到出光延迟；本进程也没有测到系统合成器的 GPU 时间或显存占用。

原始数据在本地 `artifacts/single-layer-cpu-*.txt`。更早的 CPU 纸面路径 4K 约 16.33 FPS、25.735 ms 平均渲染调用、116.41% 单核 CPU，仅作为历史基线；其代码已移除。所有构建产物和原始报告均被 Git 忽略。
